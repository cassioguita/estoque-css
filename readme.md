# 📦 Sistema Inteligente de Controle de Estoque

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido como parte da minha transição de carreira da Logística para a Tecnologia. O objetivo é unir **10 anos de experiência prática em operações logísticas** com automação em **Python** e bancos de dados **SQLite (SQL)** para resolver gargalos reais de armazém, como o controle de estoque mínimo e prevenção de ruptura.

## 🛠️ Tecnologias Utilizadas
* **Python** (Lógica de programação e automação)
* **SQL / SQLite** (Criação de tabelas, consultas e manipulação de dados)
* **Git & GitHub** (Controle de versão e portfólio)

## ⚙️ Funcionalidades
1. **Criação de Banco de Dados Local:** Estruturação automática de tabelas relacionais para produtos e níveis de segurança.
2. **Auditoria Automatizada (SELECT):** Script em Python que varre o estoque em milissegundos e alerta quais insumos estão abaixo do limite seguro de reposição.
3. **Gestão de Entradas (UPDATE):** Atualização dinâmica de quantidades no banco de dados para refletir a chegada de novas mercadorias.
