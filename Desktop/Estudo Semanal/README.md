# Plano de Estudos: Migração para Desenvolvimento Back-End

**Objetivo:** Migrar para a área de Desenvolvimento Back-End construindo uma base sólida em Lógica de Programação (Python), Bancos de Dados & SQL e Controle de Versão (Git/GitHub), aplicando esses conhecimentos em um projeto prático focado em resolver problemas reais de Logística, além de estruturar um posicionamento estratégico (LinkedIn e Portfólio) para atrair recrutadores.

Este plano alavanca seus 10 anos de experiência em logística para se destacar no mercado (especialmente em vagas de tecnologia, empresas de logística, e-commerce e instituições financeiras/bancos).
