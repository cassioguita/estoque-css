# Cronograma Semanal (Semanas 1 a 4)

## SEMANA 1: Lógica de Programação com Python + Git & GitHub para Portfólio
**Foco:** Entender a sintaxe base da linguagem e aprender a versionar seus códigos no GitHub desde o primeiro dia.
* **Dias 1 a 3 (Python Básico):** Variáveis, tipos de dados, operadores matemáticos/lógicos, estruturas condicionais (`if`, `elif`, `else`).
* **Dias 4 e 5 (Python Intermediário):** Laços de repetição (`for`, `while`), listas, dicionários e funções (`def`).
* **Dias 6 e 7 (Git & GitHub):** Comandos essenciais no terminal (`git init`, `git add`, `git commit`, `git push`, `git status`). Criar seu primeiro repositório no GitHub.
* **Mini-Desafio Prático:** Criar um script em Python que simule uma calculadora simples de frete ou validador de capacidade de carga.

## SEMANA 2: Fundamentos de Banco de Dados & SQL
**Foco:** Dominar a criação, consulta e manipulação de dados em bancos de dados relacionais.
* **Dias 8 e 9 (Conceitos & DDL):** Entender o que é um Banco Relacional (SQLite/PostgreSQL). Comandos `CREATE TABLE`, `ALTER TABLE`, tipos de dados e Chaves (Primary Key e Foreign Key).
* **Dias 10 e 12 (DML & Consultas SQL):** Comandos `INSERT`, `UPDATE`, `DELETE` e `SELECT`. Filtros com `WHERE`, ordenação com `ORDER BY` e agrupamentos com `GROUP BY` e `HAVING`.
* **Dias 13 e 14 (Cruzamento de Dados - JOINs):** Compreender e aplicar `INNER JOIN`, `LEFT JOIN` e funções de agregação (`SUM`, `AVG`, `COUNT`).
* **Mini-Desafio Prático:** Desenhar a estrutura de tabelas de um estoque (`Produtos`, `Categorias`, `Fornecedores`, `Movimentacoes`) e escrever queries para identificar itens com estoque crítico.

## SEMANA 3: Projeto Prático Integrado (Python + SQL + Logística)
**Foco:** Conectar o código em Python ao banco de dados SQL e versionar tudo no GitHub para gerar seu primeiro projeto de portfólio de impacto.
* **Dias 15 e 17 (Integração Python + SQL):** Usar bibliotecas nativas como `sqlite3` no Python para executar queries, inserir novos registros e extrair relatórios via script.
* **Dias 18 e 20 (Desenvolvimento do Projeto Logística & Tech):** Ideia do Projeto: "Sistema de Gestão e Alerta de Estoque/Rastreio de Pedidos". O script lê dados do banco, identifica gargalos/prazos estourados na operação logística e gera um resumo no terminal ou arquivo log.
* **Dias 21 (Documentação no GitHub):** Escrever um excelente arquivo `README.md` explicando o problema logístico, a solução técnica desenvolvida, como rodar o projeto e imagens/exemplos de uso.

## SEMANA 4: Introdução ao Ecossistema Back-End + Marketing Pessoal Direcionado
**Foco:** Conectar conceitos de Back-End mais amplos (como noções de APIs em Python ou sintaxe básica de Java) e otimizar seu perfil profissional.
* **Dias 22 a 24 (Visão Geral de Back-End & APIs / Java):** Entender o que é uma API REST, verbos HTTP (`GET`, `POST`, `PUT`, `DELETE`) com um framework leve em Python (ex: FastAPI ou Flask) ou sintaxe básica de Java (Classes, Métodos e Orientação a Objetos).
* **Dias 25 e 27 (Reestruturação do LinkedIn & Linktree):** Reescrever o título e o "Sobre" no LinkedIn focando na transição: “Desenvolvedor Back-End | Python & SQL | +10 anos de experiência em Processos e Logística”. Destacar projetos onde usou sistemas, planilhas avançadas, análise de dados ou otimização de rotinas no histórico profissional. Criar um centralizador de links (Linktree ou GitHub Pessoal) apontando para o seu GitHub e LinkedIn.
* **Dias 28 a 30 (Mapeamento de Vagas & Networking):** Analisar requisitos de vagas de Desenvolvedor Júnior / Analista de Sistemas em empresas de logística, transportadoras, e-commerce e bancos. Adequar os termos do seu currículo a essas vagas.
