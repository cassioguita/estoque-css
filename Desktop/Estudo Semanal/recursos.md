# Materiais e Referências Recomendados por Semana

## Semana 1 (Python & Git)
* **Cursos Gratuitos:** Curso de Python 3 do Curso em Vídeo (Gustavo Guanabara) no YouTube.
* **Git/GitHub:** Documentação oficial do GitHub (GitHub Docs - Get Started) e tutoriais interativos no Learn Git Branching.
* **Documentação:** Python Docs (Tutorial Oficial).

## Semana 2 (SQL & Banco de Dados)
* **Prática Interativa:** SQLZoo (exercícios práticos gratuitos no navegador) e W3Schools SQL Tutorial.
* **Ferramenta Recomendada:** DBeaver ou SQLite Browser (software leve e visual para gerenciar seus bancos de dados locais).
* **Leitura:** Artigos sobre modelagem de dados e normalização (1FN, 2FN, 3FN).

## Semana 3 (Projeto Integrado)
* **Documentação Python:** Módulo `sqlite3` da biblioteca padrão do Python.
* **Referência de Portfólio:** Guia “How to write a Good README” no GitHub.
* **Ferramenta de Código:** VS Code (Visual Studio Code) configurado com extensões de Python e Git.

## Semana 4 (Back-End & Marketing Pessoal)
* **Visão de APIs:** Tutoriais introdutórios do FastAPI (fastapi.tiangolo.com) ou documentação oficial do Spring Boot (Java) para noções de arquitetura.
* **Perfil & Carreira:** Modelos de perfil orientados a resultados no LinkedIn. Análise de descrições de vagas de Tech em plataformas como LinkedIn, Gupy e Catho para identificar palavras-chave essenciais (ex: SQL, APIs REST, Git, resolução de problemas, metodologias ágeis).
